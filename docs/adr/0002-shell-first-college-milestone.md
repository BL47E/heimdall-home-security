# Shell-first Ubuntu college milestone

For the ten-day Linux and shell programming college milestone, use shell scripts, a terminal menu and commands, local file storage and Ubuntu ARM64 VMs. This deliberately departs from the broader blueprint's Python, SQLite, web UI and Compose deployment so the students can implement and explain the core flow within their course and time constraints; that broader home-system direction remains future scope.

Local monitoring remains useful without credentials or connectivity. Optional Discord and VirusTotal integrations add delivery and reputation context. The owner has requested SSH source blocking in the isolated VM as the last implementation priority, with a separate detailed design review and tested console recovery before automatic network changes are enabled; the guided demonstration simulates that action and labels it. See the [milestone plan](../college-milestone-plan.md) for scope and unresolved prerequisites.

## Reproduce ordinary owner operations

Run these in blue's terminal:

```sh
~/heimdall/heimdall help
~/heimdall/heimdall status
~/heimdall/heimdall alerts
~/heimdall/heimdall config get
~/heimdall/heimdall config history
~/heimdall/heimdall demo
```

`status` reports the background monitor; `alerts` lists persisted findings. `demo` is a separate synthetic walkthrough, not a replay into live evidence. Use the IDs from `alerts` with `inspect`, `review`, `reopen` or `report`. Stop monitoring with `~/heimdall/heimdall monitor stop`; restart with `monitor start`.

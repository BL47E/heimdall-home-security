# Triage labels

These labels apply to implementation work. Wayfinder maps and decision tickets use only `wayfinder:` labels; see [Wayfinding operations](issue-tracker.md#wayfinding-operations).

| Role | GitHub label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | Maintainer evaluation is needed. |
| needs-info | `needs-info` | More information is needed. |
| ready-for-agent | `ready-for-agent` | The work is specified and ready for an agent. |
| ready-for-human | `ready-for-human` | The work needs human implementation or judgment. |
| wontfix | `wontfix` | The work will not be actioned. |
